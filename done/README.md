# Done and reusable evidence inventory

This folder records completed or reusable legacy work without treating it as a current implementation requirement.

Current reusable evidence categories include:

- existing TypeScript alert, payment, queue, overlay, RLS, reconciliation, refund, security, and UI tests;
- existing SQL migration chronology, schema snapshots, RLS scripts, test fixtures, and load-test harnesses;
- deployment/runbook, observability, trace propagation, DLQ, restore and archival evidence;
- previous research and visual-library material.

Before reusing any item, the assigned task must verify it against the current authority, source code, provider documentation, and target language. A prior “complete” claim is evidence only—not proof of v1 readiness.
