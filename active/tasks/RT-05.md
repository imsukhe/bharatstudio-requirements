## Boundaries

**Closed by the same change as RT-04**, because RT-05's fix *is* RT-04's dispatcher: the
single-row lease in migration `0129` makes concurrent dispatch runs mutually exclusive, and
no request handler scans a backlog any more. This record exists because §31.0 requires each
register row to carry its own ten fields, not because the work was separable.

**Not claimed:** that concurrent scanning was measured under load. The lease removes the
duplicate scan by construction; the pressure it was costing is a load property, and ENV-08
and RT-07 — the rows that would measure it — are Blocked.

**Out of scope:** everything RT-04's own record excludes, plus the wake-up coalescing
finding recorded in `tests/TC-RT-04-webhook-commit-and-leased-dispatcher.md`, which is a
separate follow-up and deliberately not performed.
